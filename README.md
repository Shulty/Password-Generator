
# Генератор паролей

## 📖 Описание
Простой и удобный генератор паролей, который позволяет создавать безопасные комбинации символов.  
Проект ориентирован на быструю генерацию паролей с возможностью копирования и в будущем кастомизации.

---

## 🚀 Возможности
- Генерация случайных паролей.
- Копирование пароля в буфер обмена одним кликом.

---

## 😼 Дополнительно
- Анимация печати паролей
- Адаптивная верстка

---
## 🛠️ Технологии
- **HTML5** — структура страницы.
- **CSS3** — стилизация и адаптивность.
- **JavaScript (ES6)** — логика генерации и копирования.
